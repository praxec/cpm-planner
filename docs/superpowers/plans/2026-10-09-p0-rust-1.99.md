# P0 — Pin Rust 1.99.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, test, lint and ship cpm-planner on exactly Rust 1.99.0 everywhere (local, CI, release, Docker).

**Architecture:** A `rust-toolchain.toml` pins local/contributor toolchains; `Cargo.toml` `rust-version` declares the MSRV; CI/release/Docker pin the same exact version. No source behaviour changes beyond lint fixes.

**Tech Stack:** Rust 1.99.0, cargo, GitHub Actions (`dtolnay/rust-toolchain`), Docker (`rust:1.99.0-slim`).

**Spec:** `docs/superpowers/plans/2026-10-09-backlog-roadmap.md` § "P0 — Pin Rust 1.99.0" (+ Decisions).

## Global Constraints

- Toolchain pinned: `rust-toolchain.toml` `channel = "1.99.0"`; `Cargo.toml` `rust-version = "1.99"`; CI + Dockerfile use `1.99.0` exactly.
- `rmcp` requirement bumped to `"1.8"` (Cargo.lock already resolves 1.8.0); no other dependency requirement changes.
- `cargo fmt --all --check` and `cargo test` green on 1.99.0; `cargo clippy --all-targets` produces zero warnings.
- No behaviour changes in `src/` other than lint fixes.

## Review Focus

1. **CI action input format** — `dtolnay/rust-toolchain@1.99.0` (version as the ref) must be used, not `@stable` with a `toolchain:` input that could drift; the lint job must still install `rustfmt, clippy`.
2. **Toolchain file vs CI** — with `rust-toolchain.toml` present, `cargo` in CI uses the file; the action must install the same version so no second toolchain download happens.
3. **Docker base tag exists** — `rust:1.99.0-slim` must be a real tag (verify with `docker manifest inspect` or Docker Hub API); `debian:stable-slim` runtime stage unchanged.
4. **Clippy fix doesn't change API** — removing redundant `#[must_use]` must not remove `#[must_use]` from functions whose return type isn't already must_use.

### Task 1: Pin the toolchain to 1.99.0 and clean clippy

**Files:**
- Create: `rust-toolchain.toml`
- Modify: `Cargo.toml:5` (`rust-version`), `Cargo.toml` rmcp line
- Modify: `.github/workflows/ci.yml` (two `dtolnay/rust-toolchain@stable` steps)
- Modify: `.github/workflows/release.yml` (one `dtolnay/rust-toolchain@stable` step)
- Modify: `Dockerfile:2`
- Modify: `Cargo.lock` (via `cargo update`)
- Modify: whichever `src/` files carry the 8 `clippy::double_must_use` warnings

**Interfaces:**
- Consumes: nothing.
- Produces: a branch where `cargo +1.99.0` and plain `cargo` (via toolchain file) both build; later phases may use any feature stable in Rust ≤ 1.99 and crates with MSRV ≤ 1.99 (rig 0.44 needs 1.95).

- [ ] **Step 1: Confirm the current warnings (baseline)**

Run: `cargo +1.99.0 clippy --all-targets 2>&1 | grep -c "double_must_use\|#\[must_use\]\` attribute with no message"`
Expected: non-zero (8 lib warnings).

- [ ] **Step 2: Create `rust-toolchain.toml`**

```toml
[toolchain]
channel = "1.99.0"
components = ["rustfmt", "clippy"]
profile = "minimal"
```

- [ ] **Step 3: Bump `Cargo.toml`**

`rust-version = "1.85"` → `rust-version = "1.99"`; in `[dependencies]` change the rmcp requirement `version = "1.7"` → `version = "1.8"` (keep `default-features = false, features = [...]` unchanged).

- [ ] **Step 4: Pin CI and release workflows**

In `.github/workflows/ci.yml` replace both `- uses: dtolnay/rust-toolchain@stable` with `- uses: dtolnay/rust-toolchain@1.99.0` (keep the lint job's `with: components: rustfmt, clippy`). Same replacement in `.github/workflows/release.yml`. Change the lint job's clippy step to `cargo clippy --all-targets -- -D warnings` and update its trailing comment to `# required: zero warnings`.

- [ ] **Step 5: Pin the Dockerfile**

`FROM rust:1-slim AS build` → `FROM rust:1.99.0-slim AS build`.
Verify the tag exists: `curl -s https://hub.docker.com/v2/repositories/library/rust/tags/1.99.0-slim | grep -o '"name":"1.99.0-slim"'` → prints the name.

- [ ] **Step 6: Fix clippy `double_must_use`**

For each warning location reported by `cargo clippy --all-targets`, remove the bare `#[must_use]` attribute **only** where clippy reports it (the return type is already `#[must_use]`, e.g. `Result`/`Option`-like). Do not touch other attributes.

- [ ] **Step 7: Update dependencies within existing requirements**

Run: `cargo update`
Expected: lockfile updates resolve; no requirement in `Cargo.toml` changes except rmcp.

- [ ] **Step 8: Verify on the pinned toolchain**

Run, in order:
- `rustc --version` → `rustc 1.99.0 (...)` (toolchain file in effect)
- `cargo build --all-targets` → success
- `cargo test` → all pass
- `cargo fmt --all --check` → no output, exit 0
- `cargo clippy --all-targets -- -D warnings` → exit 0

- [ ] **Step 9: Commit**

```bash
git add rust-toolchain.toml Cargo.toml Cargo.lock .github/workflows/ci.yml .github/workflows/release.yml Dockerfile src/
git commit -m "chore(toolchain): pin Rust 1.99.0 (toolchain file, MSRV, CI, Docker); rmcp 1.8; clippy clean"
```
