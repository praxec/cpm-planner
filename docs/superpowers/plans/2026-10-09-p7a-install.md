# P7a — Prebuilt Installers + MCP Install Instructions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Users and agents can install cpm-planner from verified prebuilt packages on Linux/macOS/Windows (x64 + ARM64) and register it as an MCP server in Claude Code, Claude Desktop, Cursor, VS Code, Codex and Docker by copy-paste.

**Architecture:** Salvage PR #11 (`origin/codex/prebuilt-installers`) onto a fresh branch off `dev` (`feat/p7a-install`), keeping its release workflow, installer scripts, smoke test and release-manifest tooling, and dropping its `src/` changes (superseded by P0's clippy fixes and P2's `ports.rs` rewrite). Then add a per-client install section to the README and keep `server.json` in sync with `Cargo.toml` via a CI check. PR #11 is superseded by the P7a PR (not force-pushed).

**Tech Stack:** GitHub Actions, bash, PowerShell, Node 24 (smoke/release tests), Rust 1.99.0 (pinned).

**Spec:** `docs/superpowers/plans/2026-10-09-backlog-roadmap.md` § P7a (incl. the PR #11 decision).

## Global Constraints

- Toolchain pinned: workflows use `dtolnay/rust-toolchain@1.99.0`; `rust-toolchain.toml` is the source of truth.
- No `src/` changes from PR #11 are kept. `src/` on this branch differs from `dev` only if a test in this plan requires it (none expected).
- CI must be green on ubuntu, macOS and Windows; the previously failing `test (macos-latest)` job is diagnosed and fixed (or its root cause documented with a fix).
- Installer scripts verify SHA-256 checksums before installing; no `curl | sh` without verification.
- `server.json` `version` (and package version fields) == `Cargo.toml` `version`; CI fails otherwise.
- README install snippets are tested by eye against each client's current documented config format; no invented flags. Environment variables documented: `CPM_PLANNER_DB`, `CPM_MAX_TTL_SECS`, `CPM_PROJECT_ROOT` (planned, mark "P4P"), `OPENROUTER_API_KEY` (optional, mark "P6").

## Review Focus

1. **Re-running the installer** over an existing install upgrades in place without leaving stale binaries (Task 1).
2. **Checksum mismatch** aborts the install with a clear message and non-zero exit (Task 1).
3. **ARM64 macOS/Windows** asset selection picks the right archive (Task 1 tests).
4. **`server.json` drift** fails CI (Task 2).
5. **An agent following the "agent self-install" block** ends with `plan.status`-capable server registered (Task 3 smoke step).
