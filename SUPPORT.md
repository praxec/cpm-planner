# Support

- **Questions and usage help:** start with the [README](README.md) and the
  [docs](docs/). If that does not answer it, open a
  [GitHub Discussion](https://github.com/praxec/cpm-planner/discussions) if
  enabled, otherwise a regular issue using the bug or feature form.
- **Bugs:** open an issue with the bug report form. Include the output of
  `cpm-planner --version`, your OS/architecture, your MCP client, and the plan
  file or tool call that reproduces the problem.
- **Feature requests:** use the feature request form.
- **Security vulnerabilities:** do not open a public issue. See
  [SECURITY.md](SECURITY.md).
- **Conduct concerns:** see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

This is a volunteer-maintained project; there is no guaranteed response time
for non-security issues.
